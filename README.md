# Qt/C++ 飞机大战

这是一款使用 Qt 与 C++ 手工开发的 2D 飞机大战小游戏，最初作为大一课程项目完成。项目使用 Qt Widgets 和 Qt Graphics View 构建界面与游戏场景，包含战机与弹药选择、固定关卡、自定义关卡编辑、敌我弹幕、碰撞与生命值判定、账号切换，以及本地进度和关卡数据存储。

## 项目特点

- 可选择战机和弹药，挑战预设关卡。
- 内置关卡编辑器，可配置敌机及其弹幕。
- 使用 Qt Graphics View 管理游戏场景，通过定时器更新战机、敌机、子弹和爆炸效果。
- 以继承、信号槽和对象池组织游戏对象与交互。
- 使用本地二进制文件保存账号、关卡进度和自定义关卡。

## 可改进方向

以下内容根据当前源码整理，适合作为后续维护和贡献的切入点：

- **优化碰撞检测：** 活动子弹会在每次更新时查询 `QGraphicsScene::items()`，并对候选对象执行形状相交检测。可以先通过包围盒缩小候选范围，再做精确检测；对象增多时，可以评估网格分区或集中式碰撞处理。
- **让运动不依赖定时器频率：** 当前游戏以 10 毫秒定时器驱动更新，移动量按每次更新计算。可改为按实际经过时间计算位移，并限制单次更新的最大时间步长，以减轻系统负载变化对游戏速度和流畅度的影响。
- **减少每帧工作量：** 更新循环会遍历子弹、敌机和爆炸对象池。可只遍历活动对象、跳过休眠对象，并根据实际场景测量优化效果。
- **增强存档可靠性和可移植性：** 当前存档使用自定义二进制格式及相对路径。可以增加格式版本、数据长度与范围校验、读写错误处理，并将存档放到应用数据目录；写入时使用临时文件再替换，降低中断造成损坏的风险。
- **改进密码保存方式：** 当前账号密码以原始字符写入本地文件。若继续维护账号功能，可使用带随机盐的安全密码哈希，并明确该本地账号系统不提供联网认证能力。
